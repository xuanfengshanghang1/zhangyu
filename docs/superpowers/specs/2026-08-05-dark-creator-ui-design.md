# 章鱼带货全站深色创作者工具 UI 改版

## 目标

将现有原生 HTML + CSS 官网统一为深色创作者工具风格，增强短视频带货产品的识别度和操作感，同时保留已有页面结构、SEO 文案、下载入口、截图放大和文章链接。

## 用户与设计张力

- 用户：正在比较带货软件、需要快速确认功能和获取安装包的快手矩阵团队，关注效率和可信度。
- 张力：有冲击力，但不能牺牲信息扫描效率；有工具感，但仍要让首次访问者看懂。

## 视觉系统

- 页面底色使用深煤灰，内容面板使用深蓝灰，浮层使用更亮的蓝灰。
- 保留品牌橙作为唯一强调色，用于主要按钮、当前导航、重点标签和数据标记。
- 主文字使用暖白，辅助文字使用灰蓝，边框保持低对比度。
- 阴影采用深色环境下的柔和黑色阴影，不添加紫蓝渐变、光球或装饰性背景图。
- 圆角保持约 8px，区分页面面板、内嵌控件和按钮层级，避免全部变成胶囊。
- 使用本机中文字体栈，补充 500/600 字重；大标题使用平衡换行，正文限制阅读宽度。

## 页面与布局

- 导航统一为深色半透明固定栏；当前页面链接增加橙色文字和底部标记。
- 首页保留左侧产品说明、右侧真实截图的首屏结构，调整比例和留白，避免对称卡片感。
- 更新区改为时间轴式深色面板，当前版本与历史记录层级明确。
- 功能区使用分组面板和适度不对称布局，减少白底三列卡片堆叠。
- 功能表使用深色表头、行悬停状态和更明确的分隔线。
- 截图卡片增加层级、hover 边框和高清查看提示，继续使用现有 lightbox。
- 下载区突出主操作，算法包和教程使用次级操作样式。
- FAQ、文章和教程保留适合阅读的最大宽度，并统一深色阅读面板。
- 移动端导航、按钮、表格、更新记录和页脚全部单列适配，禁止横向溢出。

## 交互与可访问性

- `assets/site.js` 根据当前 URL 标记导航的 `aria-current` 和视觉状态。
- 按钮与链接增加 hover、按下、键盘 focus 状态。
- 图片放大保留 Enter/空格打开、Esc 关闭和关闭后恢复页面滚动的行为。
- 支持 `prefers-reduced-motion: reduce`，减少用户主动关闭动画时的过渡和缩放。
- 保留更新数据加载、下载点击记录、图片放大和全部原有链接行为。

## 实现边界

- 只修改 `assets/site.css` 与 `assets/site.js`，必要时补充页面级 class，不改文章正文和 SEO 结构。
- 不引入框架、字体包或第三方运行时依赖。
- 不替换现有图片，不修改下载链接、微信联系方式、算法包链接和页面 URL。

## 验收标准

1. 首页、功能、下载、FAQ、更新日志、教程和文章页统一使用深色主题。
2. 桌面端和移动端没有横向滚动或文字溢出，导航和按钮可用。
3. 图片可以继续打开高清图，下载和文章链接保持有效。
4. 键盘 focus 清晰，当前导航有明确状态，减少动画偏好生效。
5. JSON-LD、版本信息、SEO 文案和图片 alt 文本未被删除。
6. 本地静态检查通过，并使用浏览器检查桌面与手机视口截图。
